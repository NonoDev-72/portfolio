## ✨ Overview

Portfolio is a modern React and Vite-based framework tailored for building responsive, feature-rich portfolio websites. It emphasizes developer experience, code quality, and scalability, providing a solid foundation for dynamic web projects.

**Why portfolio?**

This project streamlines the development of engaging web portfolios with a focus on maintainability and performance. The core features include:

- 🎨 **🚀 Fast Development:** Utilizes Vite for rapid module updates and hot module replacement, accelerating your workflow.
- 🧩 **🔧 Modular Architecture:** Comprises well-structured components like Header, Footer, Timeline, and Skills for easy customization.
- 🌐 **🌍 Internationalization:** Supports seamless language toggling between English and Spanish, enhancing user reach.
- 🔒 **🛡️ Code Quality & Safety:** Integrates ESLint and TypeScript for robust, error-free codebases.
- 🎯 **🎨 Theming & Responsiveness:** Built-in theming with Chakra UI ensures a consistent, adaptable UI across devices.
- ⚙️ **🔌 API & Environment Management:** Simplifies external API interactions and environment configuration for scalable development.

## 🚀 Getting Started

### 📋 Prerequisites

This project requires the following dependencies:

- **Programming Language:** TypeScript
- **Package Manager:** Npm

### ⚙️ Installation

Build portfolio from the source and install dependencies:

1. **Clone the repository:**

    ```sh
    ❯ git clone https://github.com/NonoDev-72/portfolio
    ```

2. **Navigate to the project directory:**

    ```sh
    ❯ cd portfolio
    ```

3. **Install the dependencies:**

**Using [npm](https://www.npmjs.com/):**

```sh
❯ npm install
```

### 💻 Usage

Run the project with:

**Using [npm](https://www.npmjs.com/):**

```sh
npm start
```

### 🧪 Testing

portfolio uses the {__test_framework__} test framework. Run the test suite with:

**Using [npm](https://www.npmjs.com/):**

```sh
npm test
```
